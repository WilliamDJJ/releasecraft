# Changelog

## 1.0.0 — First public release candidate

- Add a compact native desktop workflow with folder selection, measured progress, cancellation, problem details and output navigation
- Provide persistent English / Chinese controls and a Windows double-click offline installation path
- Create verified, separately owned releasecraft-output directories while retaining private audit state outside selected projects
- Preserve required Python, Notebook and Node/TypeScript resources using bounded static dependency and native-manifest evidence
- Keep secrets, unresolved dependencies, missing licenses and incomplete scans as release gates
- Produce deterministic source archives and explicit, hash-bound static and runtime results
- Include CLI and authenticated local HTTP interfaces, reproducible platform bundles and bilingual documentation

Earlier internal builds were prepublication validation builds. Their evidence and hashes do not
describe this release. The first public Git tag is v1.0; the Python package version is 1.0.0.
